### How to Run

- **Interactive Web Portal:** Open [`index.html`](index.html) in any modern web browser to view the assignments index and access individual source files.
- **Compile and Run using JDK:**
  ```bash
  # Navigate to the assignment folder
  cd Assignment-01

  # Compile Java source
  javac task1_welcome_messages.java

  # Run compiled class
  java task1_welcome_messages
  ```
- **Direct Execution (Java 11+):**
  ```bash
  java Assignment-01/task1_welcome_messages.java
  ```
